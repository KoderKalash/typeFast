## 🌟 Overview

**TypeFast** helps you sharpen your typing skills in a calm, beautifully animated dark environment.  
Inspired by Monkeytype but re-imagined with clean design principles, smooth transitions, and dual typing modes.

> 🧠 *“Type fast. Think faster.”*

---

## 🚀 Features

### 💡 Core Functionality
- 🕒 **Rush Mode (Timed)** — 30-second typing challenge with real-time WPM and accuracy tracking.
- 🧘‍♂️ **Chill Mode (Casual)** — relaxed, no-timer mode for free typing practice.
- 💾 **Local Storage** — saves your past results automatically.
- 🧹 **Clear History** — one-click deletion of saved data.
- 🔄 **Random Passages** — new text each session.
- 🎨 **Dark-Only Design** — smooth gradients, subtle animations, and consistent color palette.
- 📊 **Instant Stats** — live WPM, accuracy, and character progress.
- 💻 **Responsive UI** — perfect on mobile, tablet, or desktop.

## 🧮 Installation & Setup

```bash
# 1️⃣ Clone the repo
git clone https://github.com/<yourusername>/typefast.git
cd typefast

# 2️⃣ Install dependencies
npm install

# 3️⃣ Run locally
npm run dev

➡️ Visit http://localhost:3000
 to start typing!
```
---

## 🧭 How It Works

Select a mode — Rush or Chill.

Start typing — watch your WPM and accuracy update in real time.

When the timer ends (Rush) or when you finish (Chill), your results are saved locally.

View all your past results in the History section.

Clear history anytime or load a new passage for another round.

## 🖌️ Design Philosophy

TypeFast focuses on:

🖤 A dark-only, eye-soothing interface.

🎬 Subtle animations using Tailwind transitions and future Framer Motion upgrades.

✨ Minimal distractions — clean typography, balanced color contrast.

💨 Lightweight performance — no unnecessary libraries.
